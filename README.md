# Om Mishra — Personal Portfolio Website

A world-class, Apple keynote-style personal portfolio website built with React, Tailwind CSS, and Framer Motion.

![Portfolio Preview](https://github.com/user-attachments/assets/84e580b9-a489-4c65-b247-f7ef39eb4aca)

## Tech Stack

- **React 19** — Component-based UI
- **Tailwind CSS v4** — Utility-first styling
- **Framer Motion** — Smooth animations & scroll effects
- **Vite** — Lightning-fast build tool

## Features

- 🎬 Cinematic hero with particle field animation
- ✨ Scroll-triggered section reveals (Framer Motion)
- 🪟 Glassmorphism UI with gradient accents
- 📱 Fully responsive (mobile + desktop)
- 🖱️ Custom animated cursor
- ⚡ Parallax depth effects
- 🎨 Premium Apple-level typography & spacing

## Sections

1. **Hero** — Cinematic entry with animated name + particle background
2. **About** — Word-by-word animated bio
3. **What I Do** — Animated service cards (AI/ML, Full Stack, Product, Blockchain)
4. **Selected Work** — Cinematic project showcases
5. **Experience** — Scroll-animated vertical timeline
6. **Skills & Tools** — Interactive technology grid
7. **Contact** — CTA with social links

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The built website is output to `/dist` and can be deployed to any static host (GitHub Pages, Netlify, Vercel, etc.).
